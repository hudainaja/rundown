# Date Itinerary & Auto-Rundown Planner

Aplikasi web satu halaman (Single-Page Application) interaktif bertema **Date Itinerary & Auto-Rundown Planner** yang dibangun menggunakan HTML, Tailwind CSS, dan Vanilla JavaScript.

## ✨ Fitur Utama
- **Auto-Rundown Calculation**: Tentukan jam mulai (*Anchor Time*), jadwal kegiatan akan terhitung berantai secara instan & real-time.
- **Rangkuman Total Durasi**: Menghitung estimasi total durasi kencan dan jam selesai secara otomatis.
- **Interaktif**: Reorder (naik/turun), ubah, dan hapus agenda secara dinamis.
- **Tombol Cepat Durasi**: Preset chip durasi (15m, 30m, 45m, 60m, 90m, 120m) & kategori kegiatan cepat.
- **Salin ke WhatsApp (1-Klik)**: Format teks yang rapi dan siap kirim ke pasangan.
- **Local Storage**: Data otomatis tersimpan di peramban tanpa takut hilang saat reload.
- **Desain Responsif**: 2 kolom berdampingan pada laptop/desktop, dan 1 kolom bertumpuk rapi pada smartphone.

## 🚀 Deployment
Aplikasi ini adalah static SPA tanpa dependensi build, dapat langsung di-deploy di Vercel, Netlify, atau GitHub Pages.
